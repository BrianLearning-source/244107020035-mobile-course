# Refleksi


1. Kapan native lebih tepat dipilih daripada cross-platform?

- Penggunaan native lebih tepat dipilih ketika aplikasi membutuhkan performa yang optimal, dan akses penuh ke fitur hardware perangkat.

2. Bagaimana perubahan state berhubungan dengan widget tree dan UI deklaratif?

- perubahan state memicu framework untuk membangun ulang (rebuild) bagian widget tree yang relevan secara otomatis guna memperbarui tampilan antarmuka sesuai dengan data terbaru.

3. Mengapa commit kecil dengan pesan jelas bermanfaat bagi pekerjaan tim dan portfolio?

- Tiap commit yang disertakan pesan jelas, akan membantu tim untuk mengetahui rangkuman dari isi apa yang di commit sehingga pengguna bisa paham apa yang dikerjakan dan apa yang perlu dikerjakan
